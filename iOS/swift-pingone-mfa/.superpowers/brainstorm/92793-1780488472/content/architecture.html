LayerResponsibilityAnalogue in swiftui-mfa
AppConfiguration Calls PingOneMFA.initialize(geo: .northAmerica) once at launch. Guards re-init. AppConfiguration.swift
PingOneMFAManager @MainActor ObservableObject. Owns @Published accounts, calls getDeviceInfo(). Also holds @Published pendingNotification: MFAPushNotification? set by AppDelegate. PushManager + OathManager
AppDelegate Registers APNs, calls PingOneMFA.setDeviceToken(_:), PingOneMFA.processRemoteNotification(userInfo:), PingOneMFA.processRemoteNotificationAction(identifier:authenticationMethod:userInfo:). Posts to PingOneMFAManager. AppDelegate.swift
AppNavigationCoordinator Owns NavigationStack path + @Published showScanner: Bool (sheet). Injected as @EnvironmentObject. AppNavigationCoordinator.swift
ViewModels (3) Thin wrappers: fetch data from manager, expose loading/error state to views. AccountsViewModel, etc.
