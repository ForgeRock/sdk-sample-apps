Pairing Sheet Design

The + button opens a sheet for adding a new region. How should it work?

A

Tabbed Sheet — QR + Manual Text

Single sheet with two tabs: "Scan QR" and "Enter Key". Both use PingOneMFA.pair(pairingKey:) — QR decodes a key from the camera, text tab lets user paste/type the key directly.

+ Add Account
📷 Scan QR
⌨️ Enter Key
[Camera preview]
250×250 scan frame
B

Choice Screen → Dedicated Screen

Sheet opens with two buttons: "Scan QR Code" and "Enter Pairing Key". Each navigates to its own full screen with back button.

+ Add Account
📷 Scan QR Code
⌨️ Enter Pairing Key

Note: Both options use PingOneMFA.pair(pairingKey:) — the QR camera decodes the key from the code, the text field lets the user paste/type it. The difference is purely navigation UX.
